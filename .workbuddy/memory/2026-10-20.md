# 2026-10-20

## 新功能：打印/PDF 菜单新增「导出为 CSV 座位表」
- 需求：在「打印/PDF」选项列表增加 CSV 座位表导出，按**当前视角**导出各行列上的学生姓名。
- 实现：
  - 新增纯函数模块 `static/modules/csv-export.js`（无 DOM 依赖，可直接单测）：
    - `buildSeatCsv({ rows, cols, seats, students, viewMode, includeHeader, includePodium, emptyLabel })`
    - `buildSeatCsvFilename(title, date)` / `formatDateStamp(date)` / `escapeCsvCell(value)` / `CSV_BOM`
    - 输出 CRLF CSV；首列为 `第N排`、表头为 `排\列,第1列…`；学生视角讲台在上，教师视角行列镜像且讲台在下；
      **行/列标签始终是真实坐标**（与座位角标「X排Y列」一致）。
    - 空座位默认留空；转义覆盖逗号 / 双引号 / 换行。
  - `static/seats-generator.html`：「打印/PDF」下拉新增 `data-action="exportSeatCsv"` 的「📄 导出为 CSV 座位表」。
  - `static/seats-generator.js`：引入模块 + `exportSeatCsv()`（Blob 前置 UTF-8 BOM，避免 Windows Excel 中文乱码）
    + 下拉动作分发；`APP_VERSION` → `1.3.2`。
- 测试：
  - 单元 `static/tests/unit_seat_csv.mjs`（24 断言：学生/教师视角、转义、选项、边界、文件名）。

  - 全量单测：8 个测试文件全部通过。
