# 第五次迭代 —— 区域设置里的「当前满足情况」颜色提示(v1.4.1)

## 需求
区域设置弹窗中，已有设置项若**当前未满足**，给相应颜色提示（类似配对设置项）。

## 实现
- 判定：`currentZoneSeatMap()`（`currentSeats` + `seatZone` → `{sid:{index,zone}}`）
  + `zoneStudentStatus(student, at)` → `{status, prefBad, avoidBad, zone}`
  - `status = ''`（未设置，**不着色**）/ `ok` / `bad` / `na`（已设但未入座）
- 视觉沿用配对那套：`.zone-status-ok` 绿底 / `.zone-status-bad` 红底 / `.zone-status-na` 灰底，
  行内姓名同步染色（bad 加粗）；bad 时把**具体哪一栏**没满足的 `select` 加 `.zone-field-bad` 描红。
- `title` 说明「当前坐在「前中」 ✗ 没在倾向区域「后右」」，未入座则「尚未入座，暂无法判定」。
- 顶部汇总条 `.zone-status-line`：`当前座位:倾向 2/6 达成 · 避开 1/2 守住`（全达成加 ✓ 并转绿）；
  未入座的计入分母且算未达成。全无设置时 `hidden`。
- 刷新：打开时 / `change` 后 / `afterSeatsRender()` → `refreshZonePopupStatus()`。
- 就地刷新：`applyZoneRowStatus` 只改 class/title，不重建行 ⇒ 焦点留在刚操作的下拉上。

## 踩坑
1. `.zone-popup` 原本外壳与 `.zone-list` **双层滚动**：加了一行提示后末行被外壳切一半。
   改 `display:flex; flex-direction:column` + `.zone-list{flex:1 1 auto; min-height:120px}`，
   让列表吃满剩余高度。改完实测 `popH=518 popScroll=518`（外壳无滚动）、list 290>190 自己滚。
2. `activeZonePopup` 是文件后段的 `let` ⇒ 在 `afterSeatsRender` 里直接读会命中 TDZ，
   `typeof` 也抛 ⇒ 必须 try/catch（与 `refreshGenderHints` 同款兜底）。
3. Playwright 的 `select_option()` **不会**把焦点给 select（实测焦点仍在 `.zone-filter`），
   要验「刷新后焦点没丢」得先 `await sel.focus()`。
4. `autoSave()` 有 500ms 防抖 ⇒ 断言 localStorage 前至少等 700ms，否则读到旧值。
