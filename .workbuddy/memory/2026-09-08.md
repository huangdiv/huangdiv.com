## 新增:分组轮换(commit 7cf0546,推送 origin master 46a6538 → 7cf0546)

### 需求
随机排座新增「分组轮换」「轮换设置」:对已有分组进行座位轮换,默认按分组建立顺序
+1 循环,可自由设置 +2/+3…;人数不等时按较少一方轮换随机落座;以当前全班座位为
基准,总体座位不增不减;分组名/配色不变(人数可变化)。

### 实现
- **算法**(`random-arrange.js` 新增 `rotateGroupSeats(offset)`):
  - 分组 i 的学生 → 分组 (i+offset)%n 当前所占的座位(以「该组学生当前占据的
    座位集合 pool[i]」为轮换单位)
  - 阶段 A:每组 m = min(|bucket[i]|, |pool[dest]|),随机挑 m 人随机落 m 座
  - 阶段 B1:剩余学生优先回填自己组的空余座位(保持聚类)
  - 阶段 B2:再洗牌填满剩余空位(数学保证 Σ剩余学生 == Σ空位,i→(i+k)%n 是
    索引置换)
  - 硬约束:只重排已入座且有分组的学生;无分组学生原地不动;newSeats 先腾空
    分组座位再回填 → 占座总数恒等;写回用就地赋值保持 state.seats 引用
    (保护 currentSeats 别名)
  - 自检:占座总数 + 重复占座,异常写入 warnings 返回 toast
  - 步长归一:0/负/超界/NaN → 折回 1..n-1
- **UI**(`seats-generator.js/.html/.css`):
  - 「随机排座」下拉新增两项:`rotateGroups`(徽标 `+N`)、`rotateSettings`
  - 轮换设置弹窗复用 pair-popup 体系:步长数字输入**输入即生效**(纯配置,
    同步徽标+预览+autoSave),源组→目标组预览映射(含各组人数),
    「立即轮换」「关闭」;fixed 定位/焦点陷阱/Esc/外点关闭全套
  - `groupRotateOffset` 持久化到 config;`updateGroupDisplay()` 尾部统一
    normalize+徽标同步(分组增删后自动收敛)
  - 新增 `.dropdown-item-badge` 徽标样式 + `.rotate-*` 弹窗样式
- **消息**:`messages.js` 新增 ROTATE_NO_GROUPS / ROTATE_NO_SEATED /
  CONFIRM_ROTATE / ROTATE_DONE 等

### 测试
- 新增 `static/tests/unit_rotate_groups.mjs`(19 项):等人数轮换落区 /
  人数不等 min 规则 / 硬约束(总数/无重复/无分组学生不动/学生集合不变) /
  边界(<2 组、无人入座、取消)/ 步长归一 5 例 / 分组元信息不变 /
  压力(20 组随机规模×8 seed)
- 新增 `.workbuddy/smoke_test_batch13_group_rotate.py`(23 项):下拉项与徽标 /
  不足 2 组提示 / +1 轮换落区 / 弹窗预览与步长修改 / +2 轮换 / 人数不等 /
  分组元信息 / 撤销恢复 / 步长持久化 / 无报错
- 回归:batch5/6/8/9/10/11/12 + dragdrop/seat_grid/e2e + 单元 86 全过
