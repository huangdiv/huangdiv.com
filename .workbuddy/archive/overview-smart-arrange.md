# 打印日期同行 + 「智能排座」分段按钮

commit `7b2f46f`(4b90add → 7b2f46f),已推 origin master。改动 3 个文件 +398/−226。

## 1. 打印/导出:日期与标题同一行

**改动前**:打印时把日期 `appendChild` 进 `contenteditable` 的 h1 —— 日期会随标题一起被保存,污染标题内容;标题用 `left:50%/translateX(-50%)` 自居中,日期无法稳定同行。

**改动后**:
- `h1#pageTitle` 外包 `.page-title-row`,日期为独立兄弟节点 `#titleDate`
- 居中改由父层 `text-align:center`,h1 保持 `inline-block`(屏幕/打印皆是)
- `@media print` 下 `.title-date` 显示(9pt、#666、接在标题后)
- 导出图片改为克隆整个标题行,并强制 `display:inline-block` + 写入当天日期

## 2. 随机排座 → 智能排座(上下两段)

```
┌──────────────┐
│ ⇄ 智能排座    │  ← 上段:按下方开关直接执行
├──────────────┤
│      ▾       │  ← 下段:展开选项菜单
└──────────────┘
```

菜单内容:
| 项 | 类型 | 说明 |
|---|---|---|
| 男女同桌 | 开关 | 与「男女不同桌」互斥,默认关 |
| 男女不同桌 | 开关 | 与「男女同桌」互斥,默认关 |
| 小组轮换 | 开关 | 默认关;开启后出现「轮换步长 − 1 +」 |
| 配对设置 | 菜单项 | 沿用原入口 |

- 两个性别开关都关 = 完全随机
- 步长边界 1 ~ (分组数 − 1),到边界按钮自动禁用
- 开关与步长写入 config(`smartArrangeMixed/SameGender/Rotate`)并即时持久化
- 执行后自动收起选项菜单
- 移除独立的「轮换设置」弹窗,步长在下拉内直接调;排座与轮换的提示合并为一条 toast
