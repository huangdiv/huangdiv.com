# 分组模式 · 多选焦点优化 — 任务概览

## 本次完成内容

修订上一版「分组查看态」的交互,解决「多选学生」与「查看分组」两种焦点互相争抢的问题。

| 改动 | 说明 |
|------|------|
| 点击分组按钮 | **仍**高亮该组全部成员(查看态保留) |
| 点击学生 | **去掉**「整组高亮」,只保留该生多选高亮(`.group-selected`) |
| 多选时统计栏 | 当前学生姓名 / 所属分组(着组色) / 已选人数(可点,弹菜单复制姓名·下载 Excel) |
| 统计栏字号 | 三项统一 22px,与普通/签到模式一致,等宽 + 长文本省略号 |

## 关键实现

- 删除 `setGroupFocusByStudent()`;新增 `dropGroupFocusIfViewing()`(选中学生时才清查看态)。
- 新增 `groupCurrentStudentId`(最后点击的学生),统计栏据此展示「当前学生」。
- `updateGroupStatsRow()` 重写为三槽结构(`groupStatSlot1/2/3`),按状态分三支:
  多选中 → 当前学生/所属分组/已选人数;查看态 → 当前分组/分组人数/即将轮换到;
  其余 → 未选择/0/—。可点项动态赋 `data-stat` + 事件委托。
- 分配完成后顺势 `groupFocusId = 目标组`,直接查看目标分组。
- `getStatContext()` 新增 `groupSelected` 分支(多选学生按名单顺序取)。
